Welcome to Smart Logistics

Smart Logistics is a delivery route optimization system that uses four different algorithmic approaches to find the shortest path between delivery locations.

Problem Description

Delivery companies need to find efficient routes between locations to reduce travel distance and cost. This application compares four algorithms that solve the shortest delivery path problem.

Why is it important?

  • Reduces delivery distance.
  • Saves fuel and transportation costs.
  • Improves delivery efficiency.
  • Helps compare different algorithms.

Project Objective

Calculate the shortest path between a starting location and a destination using four approaches.
